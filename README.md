# LDS1101 — Programación Concurrente

## Compilar las actividades 11 y 12

Puedes compilar el **código Java** con el JDK (`javac` y `java`) y generar el **reporte PDF** con MacTeX o TeX Live (`latexmk`). Los comandos exactos para cada ejercicio están en sus respectivos README:

- [Actividad 11: filósofos comensales](11%20Problema%20de%20los%20filosofos%20comensales/readme.md)
- [Actividad 12: implementación de monitores](12%20Implementacion%20de%20monitores/readme.md)
- [Plantilla LaTeX compartida](latex_compartido/README.md)

El PDF final está en la raíz de cada actividad. La carpeta `build/` conserva los auxiliares. Cuando actualizas los `.tex` de las actividades 11 o 12 en `main`, GitHub Actions los compila y registra los PDF y auxiliares.
