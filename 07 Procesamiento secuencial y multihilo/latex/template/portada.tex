\begin{abbreviations}
  \item[CPU] \textit{Central Processing Unit}: unidad central de procesamiento.
  \item[JVM] \textit{Java Virtual Machine}: máquina virtual que ejecuta el
  bytecode de Java y permite que los programas se ejecuten sobre distintos
  sistemas operativos.
  \item[OS] \textit{Operating System}: sistema operativo.
  \item[PID] \textit{Process Identifier}: identificador del proceso.
  \item[PPID] \textit{Parent Process Identifier}: identificador del proceso padre.
  \item[POSIX] \textit{Portable Operating System Interface}: conjunto de
  estándares que define interfaces y servicios comunes para sistemas
  operativos tipo Unix, como las funciones \texttt{fork()} y \texttt{wait()}.
\end{abbreviations}
